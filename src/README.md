# Source Code

This folder contains the Python scripts responsible for feature extraction, model training, testing, and utilities for image processing.

## Files:

- **`ANN.py`**: Code for the Artificial Neural Network model.
- **`CNN.py`**: Code for the Convolutional Neural Network model.
- **`compute_hist.py`**: Helper script for histogram-based feature extraction.
- **`compute_statistics.py`**: Script to compute statistical features from image regions.
- **`KNN.py`**: KNN classification model code.
- **`load_data.py`**: Code to load the dataset.
- **`process_dataset.py`**: Preprocessing and feature extraction script.
- **`split.py`**: Script to split the data into training and test sets.
- **`stats.py`**: Helper functions for statistical analysis.
- **`SVM.py`**: Support Vector Machine classification model code.
- **`test_with_image.py`**: Code to test models on individual images.

These scripts are responsible for all steps of the project, from data loading and processing to model training, testing, and evaluation.
